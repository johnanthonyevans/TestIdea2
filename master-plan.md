# TestIdea2 — Master Plan

## What Is TestIdea2
A minimal hello-world project used to validate Drift's full lifecycle — from master plan creation through drifts, PRs, evals, and syncs.

## Top-Line Goals
1. Verify Drift's end-to-end workflow functions correctly
2. Serve as a sandbox for testing new Drift features

## Guiding Principles
### Keep It Minimal
This project exists to test Drift, not to build real software. The codebase should stay as simple as possible.
### Break Things Here
This is the safe space to push Drift's edge cases — nothing in this repo is precious.
